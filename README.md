# מסלול FLEX

משחק אינטרנטי ללימוד Flexbox בנושא חלל. המשתמש כותב CSS, מריץ אותו על צי החלליות, ובודק אם הצליח להשלים את המשימה.

## הפעלה

הפרויקט בנוי מ־HTML, CSS ו־JavaScript בלבד ואינו דורש התקנת חבילות.

1. פתחו את תיקיית הפרויקט ב־VS Code.
2. הפעילו שרת מקומי, לדוגמה:

	```powershell
	python -m http.server 8000
	```

3. פתחו בדפדפן את `http://localhost:8000`.

אפשר גם לפתוח ישירות את `index.html`, אך שרת מקומי מומלץ לצורך בדיקה זהה ל־GitHub Pages.

## מבנה הפרויקט

- `index.html` - מבנה העמוד, הוראות המשחק ועורך הקוד.
- `style.css` - עיצוב, פריסת Flexbox, רספונסיביות ופונטים מקומיים.
- `script.js` - השלבים, הרצת CSS, בדיקת פתרונות, ניקוד ושמירת התקדמות.
- `assets/` - קבצי הפונטים המקומיים של האתר.

## איך משחקים

בכל שלב מופיעה הוראה וטיפ קצר. כותבים בעורך את מאפייני ה־Flexbox, לוחצים על **הצגת התוצאה**, ואז על **בדיקת הפתרון**. לאחר הצלחה עוברים אוטומטית לשלב הבא.

המשחק כולל שישה שלבים ומשתמש במאפיינים `display: flex`, `flex-direction`, `justify-content`, `align-items` ו־`flex-wrap`.

## פרסום ב־GitHub Pages

העלו את כל הקבצים למאגר ציבורי, וב־GitHub פתחו `Settings` > `Pages`. בחרו בפרסום מהענף הראשי (`main`) ומהתיקייה הראשית (`/root`). לאחר הפרסום, GitHub יציג את כתובת האתר החי.

## משאבים חיצוניים

אין בפרויקט תלות ברשת, בספריות JavaScript או בשירותים חיצוניים. הפונטים נשמרים מקומית בתוך `assets/`.
